# Usage Review Cadence

Purpose: define how v34.2 should be used during the development pause.

## After every measurement session

Record anything that was confusing, slow, repetitive or error-prone in `BUG_FEEDBACK_LOG.md`.

## After every website export

Record whether the HTML export was correct, whether upload/publish went smoothly, and whether the website looked correct in the browser.

## After every YouTube recording session

Record whether the dashboard and reports supported the video workflow well, especially filtering, chart readability and comparison sections.

## Weekly review

Once per week, review the notes and mark each item as:

- Bug
- Usability
- Documentation
- Website
- Report
- Future idea

## Next development cycle trigger

Start the next development cycle when one of these is true:

- A blocking bug appears.
- The same workflow annoyance appears repeatedly.
- A website publishing issue affects YouTube work.
- Enough real-world feedback has accumulated to justify a focused polish release.
