# v19.4 Recommendation → Video Planner

This milestone connects the Recommendation Engine to the Video Planner workflow.

## Workflow

1. Open the Recommendations tab.
2. Select a recommendation row.
3. Review the detail panel.
4. Click **Send to Video Planner**.
5. Open the Video Planner tab.
6. The recommendation appears at the top of the candidate list as a `Recommendation idea`.

## Included fields

The generated Video Planner candidate includes:

- Suggested title
- Thumbnail hook / angle
- Talking points
- Recommendation type
- Why the material was recommended
- Placement / score context

This is intentionally an in-memory workflow step for now. It helps move a recommendation into the planning list without changing the imported Excel data.
