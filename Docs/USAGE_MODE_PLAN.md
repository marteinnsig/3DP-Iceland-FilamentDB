# Usage Mode Plan

## Goal

Use the application as the primary production workflow for a real data-collection period. The goal is to discover practical workflow issues that only appear during normal daily use.

## Focus for the pause

- Print more specimens.
- Add new materials.
- Enter measurements in the app.
- Recalculate native results.
- Export and review website HTML.
- Use the website in YouTube video preparation and recording.

## Suggested note-taking format

Use short notes. Do not over-document while testing.

Example:

```text
Date:
Area: Materials / Measurements / Website Export / Reports / UI
What happened:
Expected behavior:
Severity: Bug / Friction / Idea
```

## Next development cycle

When the usage period is complete, group feedback into:

- Bugs.
- Workflow improvements.
- UI polish.
- Website/export improvements.
- Reporting improvements.
- New platform ideas.
