# Video Planner

The Video Planner helps identify materials and comparison ideas for future 3DP Iceland Labs videos.

## v18.0
- Added the Video Planner tab.
- Added basic filters for video status and mechanical data readiness.
- Listed candidate materials based on YouTube review status, website profile status, and imported mechanical data.

## v18.1
- Added data-aware suggestion fields.
- Candidate rows can now be flagged for standout tensile, impact, stiffness, consistency, or layer-adhesion performance.
- Suggestions compare each material against a peer group where possible.

## v18.2
- Added automatic comparison discovery.
- The planner now scans mechanically tested materials and proposes comparison groups.
- Supported comparison types:
  - Reinforcement comparisons, such as CF vs GF vs pure.
  - Manufacturer battles inside the same base material.
  - Product-line comparisons.
  - Variant / finish comparisons.
- Each comparison idea includes a suggested winner, the largest story axis, a short reason, and a possible title angle.

## v18.3
- Added data-driven title suggestions for candidate materials.
- Added hook / angle text and talking points based on the strongest radar-score dimensions.
- Automatic comparison discoveries now include a suggested video title, title angle, and talking points.
- Title suggestions follow the current 3DP Iceland Labs style, such as test-result hooks, comparison framing, and “what is it actually good for?” angles.

The planner is intentionally read-only. It does not create scripts or publish queues automatically yet.
