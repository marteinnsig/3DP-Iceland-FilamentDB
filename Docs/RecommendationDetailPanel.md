# v19.3.3 Recommendation Detail Panel

This step changes the Recommendation Engine from an expanding-row table to a workflow-style layout.

## Changes

- Recommendation tables stay compact and scrollable.
- Selecting a recommendation opens a fixed right-side detail panel.
- The detail panel shows:
  - recommendation type and place
  - selected material
  - score and material type
  - suggested video title
  - thumbnail hook
  - talking points
  - why it matters
  - best use
  - caution / trade-offs

This prepares the next step: sending a recommendation directly into the Video Planner.
