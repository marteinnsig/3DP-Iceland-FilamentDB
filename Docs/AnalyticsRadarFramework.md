# Analytics & Radar Framework

This milestone adds the desktop-app foundation for the website analytics model.

## Website-aligned chart mode

The app now supports the same chart mode idea as the website:

- All filament samples
- Average by material type
- Average by manufacturer
- Average by product line
- Average by variant / finish
- Average by reinforcement

The first implementation shows the calculated chart data in a table. The next milestone can render the same data as a radar overlay.

## Radar axes

The app uses the same five axes as the website performance profile:

- Tensile
- Impact
- Stiffness
- Consistency
- Layer Adhesion

## Filtering

The Analytics tab uses the visible material list, so the main search box and left-side filters affect the analytics rows.

The filter panel now includes:

- Manufacturer
- Product Line
- Base Material
- Category
- Variant / Finish
- Reinforcement
- Color

## Notes

The current scoring engine still uses first-pass normalization references inside the desktop app. The long-term goal is to fully align the scoring with the website export/ranking pipeline or replace the website export with data generated by the desktop app.
