# Recommendation ChatGPT Prompt

v19.3.5 adds a copy/paste prompt section to the Recommendation Detail panel.

The prompt collects:
- recommendation type
- material
- score
- suggested title
- thumbnail hook
- talking points
- reason
- best use
- cautions

The text box is read-only but selectable so it can be copied into ChatGPT for more creative title and thumbnail refinement.
