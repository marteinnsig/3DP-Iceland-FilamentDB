# Reporting Engine

The reporting engine was developed through the v22-v23 series.

## Capabilities

- Report export foundation.
- Report preview templates.
- Material report generation.
- Report type layouts.
- Native/real PDF generation.
- Rich PDF report content.
- Chart and visual analytics support.
- Selected/global material report scope.

## Design goal

Reports should be useful outside the application: printable, shareable and suitable for material comparison or documentation.
