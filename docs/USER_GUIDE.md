# User Guide

Version: v29.4 WEB-005 - Website Verification Suite

## Website Export

Use the Website Export tab exactly as before.

Before publishing:

1. Open Help > Verification Center.
2. Click Recalculate Native Results.
3. Confirm Overall Verification: PASS.
4. Confirm Website Publish Readiness: READY FOR PUBLISH.
5. Generate Preview and review index-test.html.
6. Only then create production index.html.
