# Material Collections

## v26.4 - Material Collections

Material Collections let the AI Assistant work with reusable sets of materials.

## Visible App Features

- Intelligence scope selector:
  - Current visible rows
  - Selected collection
- Collection title field.
- Collections dropdown.
- Save Visible as Collection.
- Load Collection Brief.
- Delete Collection.

## Workflow

1. Use filters or search in the material database to create a focused material set.
2. Open AI Assistant.
3. Enter a collection title.
4. Click Save Visible as Collection.
5. Later, select that collection and set Intelligence scope to Selected collection.
6. Use Recommended Next Video, Recommended Comparisons or Hidden Gems against that saved collection.
7. Delete old collections when a video series is finished.

## Storage

Collections are saved locally as JSON in the same application data folder as AI Assistant sessions.
